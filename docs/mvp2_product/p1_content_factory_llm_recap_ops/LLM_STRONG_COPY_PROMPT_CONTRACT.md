# P1 · LLM_STRONG_COPY_PROMPT_CONTRACT

> The contract for attractive, sharp, grounded prediction copy. Prompt generated by
> `mvp2_build_daily_prediction_artifact.py build_prompt`; quality enforced by
> `scripts/check_llm_copy_quality.py`. Auto-LLM is P1-of-P1; today provider=operator_manual (the
> operator pastes the prompt into DeepSeek/Gemini/Kimi, reviews, saves the JSON). No auto-call.

## The prompt MUST force

- strong headline / main lean (a clear directional call, not "both teams have chances")
- main call (primary_score) + backup scores
- risk level + top tactical variable
- a tactical story (≥2 tactical_read beats)
- data/source basis (cite the ScoutScore facts: Elo gap, last-10 form, Poisson band)
- external expectation in SAFE wording (public tendency / heat / upset variable — never odds)
- T-30 checklist (5 items)
- share copy (homepage-short + /predict-medium + social are all derivable from the artifact i18n)
- multilingual zh/vi/my/en (the artifact i18n carries all four; vi/my Han=0)

## Tone
confident · sharp · tactical · engaging — but NOT fake, NOT gambling, NOT overclaiming. Forbidden:
odds/handicap/盘口/赔率/投注/让球/kèo/cửa trên-dưới/betting/bookmaker; win-rate/胜率/命中率/tỷ lệ thắng;
any win-guarantee phrasing (稳赢/必胜/chắc thắng — even negated, avoid the literal token).

```json
  "risk_level": "低|中|中高|高",
  "risk_note": "string (cites data basis)",
  "top_variable": "string",
  "why": "string",
  "tactical_read": ["…", "…", "…"],
  "risk_factors": ["…", "…", "…"],
  "external_expectation": ["公开预测倾向…", "热度集中…", "冷门变量…"],
  "t30_checklist": ["…","…","…","…","…"],
  "share_copy": "string (strong, no forbidden vocab)",
  "llm_provider": "deepseek|gemini|kimi|operator_manual",
  "safety": { "no_betting_vocab": true, "no_fake_probability": true, "no_auto_send": true }

```

## Copy-quality guard (`check_llm_copy_quality.py`) — REJECTS
generic fillers (双方都有机会 / 需要关注临场变化 / both teams have chances); missing headline/score/
top_variable/why/tactical story/data basis/share copy; betting vocab; fake probability.
**REQUIRES** all of the above present and non-trivial, for every PUBLISHED match in the queue.

## Grounding (cross-checked by `check_llm_grounding.py`)
The reviewed `primary_score` must equal `model_fields.recommended_score` (or `risk_level` must echo),
so the copy is provably grounded in the computed/estimated model — not free-floating. Verified today
for Belgium-Egypt (computed 1-0), Saudi-Uruguay (computed 0-1), Spain-CapeVerde (operator_estimated 2-0).
