# Giành Cup · Operation Copy Test Pack

_Version: MVP v0.7 · Created: 2026-06-06 · Human-authored (NO LLM)._

Four reusable copy templates for the accelerated operating trial, plus a community承接
checklist. Examples are filled from the current 3 live matches (seed data):
BRA-ARG, MAR-FRA, ESP-GER.

**Style rules:** Vietnam-first market · Chinese primary, light English titles OK ·
strong conclusions · short sentences · emotional tension · **never** use
必中/稳赚/跟单/下注/回报率/奖池/收益 or any betting wording · always「AI 倾向 / AI 数据观点」·
carry the disclaimer where 战绩/命中/连胜 appears.

Mandatory disclaimer string:
> 历史表现不代表未来结果，仅供数据分析和球迷娱乐参考。

**Filled example (巴西 vs 阿根廷，真实 live_correction 数据):**
```
【临场情报更新】巴西 vs 阿根廷

修正后 AI 倾向：主 49% / 平 26% / 客 25%
```

| Check | Current status (2026-06-06) | Action |
|-------|------------------------------|--------|
| Zalo 真实链接 | ❌ 无（`coming_soon`, `public_url: null`） | Day B 提供真实链接或建测试群 |
| Telegram 真实链接 | ❌ 无（`coming_soon`, `public_url: null`） | 同上 |
| 无真实链接时建测试群 | ⏳ 待运营 | 至少建 1 个 Zalo/Telegram 测试群 |
| `admin/social/channels/upsert` 可设 `active` | ✅ 端点就绪（admin token，Render Shell） | 配置时设 `status:"active"` + `public_url` |
| `click_social_channel` 可统计 | ✅ 已验证 `{ok:true,"recorded"}` | 点击事件**需带 `match_id`** 才计入 heat |
| community heat 是否更新 | ✅ 带 match_id 的事件会更新 heat | 渠道点击归因务必传 match_id |

**配置真实链接示例（仅在 Render Shell，token 不打印）：**
```bash
curl -X POST https://worldcup2026-api-71n6.onrender.com/api/v1/admin/social/channels/upsert \
  -H "Content-Type: application/json" \
  -H "x-admin-token: $ADMIN_API_TOKEN" \
  -d '{"channel_name":"zalo","display_name":"Zalo 越南球迷群",
       "description":"每日 AI 情报、临场修正第一时间推送",
       "public_url":"https://zalo.me/YOUR_GROUP_ID",
       "status":"active","locale":"vi","is_enabled":true,"sort_order":1}'
```

> **硬规则：真实链接绝不硬编码进代码**，只通过 admin API 配置。优先级 Zalo → Telegram → Facebook → TikTok。
