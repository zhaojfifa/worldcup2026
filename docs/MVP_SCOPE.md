# MVP Scope

## 7 天 MVP 目标

完成一个可公网演示的 2026 世界杯 AI 情报中心。

## 必做范围

- 首页 / AI 预测卡片流
- 单场预测详情页
- 完整 AI 报告页
- MTC 积分中心
- 社群订阅页
- 自动 fixtures / teams / match status 同步
- Baseline AI 预测
- 自动解释报告
- 赛前 30 分钟临场修正
- Token 签到、预测挑战、报告解锁
- Render 部署
- Cloudflare R2 存储预留

## 暂不做

- 完整机器学习训练平台
- 真实博彩
- 真实现金奖池
- Token 提现
- 链上 Token
- 高并发正式世界杯架构
- 完整多语言运营后台
