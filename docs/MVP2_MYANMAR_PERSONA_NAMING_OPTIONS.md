## 3. 小范围试用期最终建议

1. **试用期（现在）**：用 **Football Oracle**（已实装、guard 已绑定）。理由：安全、无合规
   联想、不阻塞试用；缅语名错配的成本（改名重生成 8+ 份叙事 + 群内认知重置）远高于晚两周定名。
2. **试用反馈要收的题**（已写入运营包 §15 缅甸反馈清单）：
   - "Football Oracle" 听起来自然吗？要不要缅语名？
   - 候选 A（ဘောလုံးအကဲခတ်）/ B（ဘောလုံးပညာရှင်）哪个更像"会看球的人"？
   - 有没有任何叫法让你联想到赌球荐单（ဘောဆရာ 文化）？
3. **若 Owner 要求缅语名**：首选 **A ဘောလုံးအကဲခတ်**（专业-中性-可人格化），
   备选 B；**C / D 因博彩与宗教联想分别排除**。
4. 定名后工序（一次性）：mm.ts/组件 my 标签替换 → my prompt persona 行替换 →
   guard persona 词替换 → 8 份 my 叙事重生成 → 可见文案扫描复跑。预计 ≤ 半天。
